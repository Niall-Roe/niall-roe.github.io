Signal Detection & Hypothesis Testing

An app for exploring signal detection theory and Neyman–Pearson hypothesis testing, set out to show that the underlying mathematics is essentially the same. Use the Parameters and Simulation tabs to see how moving the threshold trades one kind of error against the other, and how observed frequencies settle towards the theoretical rates. Switching between the SDT and Neyman–Pearson views keeps the same picture and changes only the labels. The Comparison tab makes that correspondence explicit.

Finley's tornado forecasts, 1884: 2803 occasions, 51 of them tornadoes. Peirce wrote about this data the same year, arguing that a forecaster's accuracy tells you little when the event being forecast is rare, and proposing the measure now known as the Peirce Skill Score.
