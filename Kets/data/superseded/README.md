# Superseded — do not use for the kats

`weights.csv` and `tidied.csv` are the earlier transcription of the full
Naukratis I table (516 weights, all standards). Their Egyptian Kat rows contain
~65 rows with errors (dropped decimal points, digit slips, wrong materials, a
wrong multiplier). The verified replacement for the kats is
`../naukratis1888-kat.csv`; see `../README.md` for the verification record.

Kept because the non-kat standards (Assyrian, Phoenician, Attic, …) have no
other transcription yet. If one of those is ever needed, verify it against
`texts/petrie1888.pdf` pp. 76–79 first, the way the kat rows were.
