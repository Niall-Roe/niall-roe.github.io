##### the original suggestion, for reference

Edit this to say:

This excerpt arrives [x] manuscript pages into the article. Peirce is discussing classification. In general, a class is the set of things that answer to a certain description. We usually classify with a purpose, so we might want to have a class of all red things for an art project, or want to classify planets or mammals in a certain way to make them tractable in scientific applications. A class is /natural/ when it picks things out according to /their/ purposes rather than ours. So my red pencil sharpener can be a member of the class of red things, but it is naturally part of the class of things that sharpen pencils. For Peirce, there is a purpose wherever there is a process of development. this process can be natural, as in evolution, or agent-led, as in design. 

Here, he is arguing that natural classes do not have sharp boundaries, which means that they can occasionally  overlap. He illustrates this examples with a sustained piece of practical statistics using an archaeological dataset: the Egyptian balance-weights excavated by Flinders Petrie at Naucratis.
